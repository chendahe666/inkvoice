# 使用墨声

## 第一段语音输入

1. 启动墨声，在“设置”中选择麦克风和识别语言，然后保存。
2. 将光标放到需要输入文字的应用中。
3. 按工作台显示的录音快捷键开始。首选为 `Ctrl + Alt + Space`；如果被占用，启动时会尝试其他组合。以当前显示的快捷键为准。
4. 说完后再次按同一快捷键结束，等待本机识别。
5. 检查结果。可以修改“成文”、复制文字，或使用写入快捷键。

工作台的“开始录音 / 结束录音”按钮也可以使用。单次最长 5 分钟；过短或几乎无声的录音会给出提示。当前版本在停止后开始识别，不会实时逐字显示。

## 写入目标应用

“自动写入原应用”默认开启。使用全局快捷键开始录音时，墨声记录当时的前台窗口；识别完成后，只有该窗口仍在前台时才尝试自动写入。

如果切换了窗口，或从墨声主窗口点击录音，结果可能保留在工作台。回到目标输入框，按 **`Ctrl + Alt + V`** 写入当前结果，也可点击“复制文字”后手动粘贴。

- “写入当前结果”使用你编辑后的成文。
- 在历史列表中选择“在工作台查看”后，那条记录会成为当前结果。
- 原始转写只读；录音、识别和云端处理期间，成文暂时只读。
- 清空成文后，它保持空白，不会自动恢复原始转写。

自动输入依赖 Windows 焦点和权限机制。管理员窗口、游戏、特殊编辑器或某些受保护输入框可能不接受输入；不要在密码框中试录。失败时先检查目标窗口，再使用复制方式。

## 三种文字模式

| 模式 | 实际处理 | 是否需要 API 密钥 |
|---|---|---|
| 原文 · 本地 | 本机识别，清理空白并应用明确的词表替换 | 否 |
| 整理 · 云端 | 将转写文字和词表发送至 Gemini，整理口语、标点与段落 | 是，使用你的 Gemini 密钥 |
| 翻译 · 云端 | 将转写文字和词表发送至 Gemini，输出设置中的目标语言 | 是，使用你的 Gemini 密钥 |

本地模式不自动执行语言翻译。可在“设置”中手动选择识别语言，或保留自动检测。

### 配置 Gemini

1. 在“设置 → 云端整理与翻译”输入自己的 Gemini API 密钥，点击“保存密钥”。
2. 根据账户权限填写可用模型名称；默认名称可能随服务可用性变化。
3. 需要翻译时选择目标语言并保存设置。
4. 回工作台主动选择“整理”或“翻译”。

也可在启动墨声前设置 `GEMINI_API_KEY` 环境变量。仅存在密钥不会启用云端模式；已经保存的密钥优先于环境变量。不要把密钥写入仓库、命令截图或问题反馈。

云端请求只包含文字和词表，不包含录音、屏幕或光标附近文字。云端服务的费用和额度由你的账户承担。重要姓名、数字、事实和译文应人工核对。

云端处理失败时，本地转写会保留，该次自动写入暂停。可以复制结果，或在修改成文后点击“重新整理”；重试以当前成文为输入，原始转写保持不变。

## 个人词表

在设置中每行写一个姓名或术语，作为本地识别及可选云端处理的词汇提示。提示不会保证识别正确。

确定的替换规则可以写成：

```text
InkVoice
墨声
因克沃斯 => InkVoice
项目代号阿尔法 => Alpha
```

只有写明来源和目标的规则才执行确定性替换。云端模式开启时，词表中的目标词也会发送至 Gemini。

## 导入音频

点击“导入 WAV”，选择 **16 kHz、16 位、单声道 PCM WAV**。当前不直接接受 MP3、M4A 或其他 WAV 编码；需要先在其他音频工具中转换格式。

导入音频同样受 5 分钟和大小限制；内置麦克风会自动生成支持的格式。导入结果只显示在工作台，不自动写入其他应用。

## 记录、托盘与退出

默认保存最近 30 条文字记录，包括原始转写和成文，不保留长期音频库。编辑成文会同步更新对应记录。

- 单条“删除”移除该历史记录；“清空记录”删除整个历史列表。
- 在设置中关闭“保留文字记录”会清空已有记录，并停止保存新记录。
- 关闭主窗口或点击“后台运行”会隐藏窗口，录音和快捷键仍可工作。
- 通过托盘菜单打开窗口；要结束应用，选择“退出墨声”。

## 数据保存在哪里

| 内容 | 默认位置 |
|---|---|
| 便携版设置、加密密钥与明文历史 | `InkVoice.exe` 旁的 `data` 目录 |
| 开发版设置、加密密钥与明文历史 | 项目根目录的 `data` |
| 临时录音及识别中间结果 | 系统临时目录中的 `InkVoice-audio` |

正常完成、失败或取消识别后会清理该任务的临时文件。崩溃、强制结束或系统关机可能留下未清理文件；退出墨声后可检查该临时目录。

文字历史没有加密。密钥只有在系统加密可用时才加密保存，复制便携目录不意味着密钥能在另一台电脑或另一账户下解密。分享应用应使用新构建，避免附带自己的 `data`。

问题排查见 [安装说明](INSTALL.md#常见问题)，敏感问题见 [安全说明](../SECURITY.md)。
